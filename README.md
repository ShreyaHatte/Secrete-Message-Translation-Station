🔐 Secret Message Translation Station

A Python-based desktop application that allows users to securely encode and decode messages using the Caesar Cipher technique. The project features a user-friendly GUI built with Tkinter, where users can enter a message, apply a secret key, and instantly view encoded or decoded results.

The application also includes message history storage using file handling, enabling users to view past operations and reuse previous inputs through a dropdown menu. This project demonstrates core concepts of Python such as object-oriented programming (OOP), GUI development, and basic cryptography.

🚀 Features
Encode and decode messages using Caesar Cipher
Simple and interactive Tkinter GUI
Message history storage and retrieval
Input validation for secure operations
Dynamic dropdown for previously used messages

🛠️ Tech Stack
Python
Tkinter
File Handling
OOP Concepts
